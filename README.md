# Alpha FaultLab

Standalone, read-only educational simulator for Alpha Connect. Open `index.html` locally or deploy using GitHub Pages (Settings → Pages → Deploy from branch → main → root).

Includes 13 modules, guided simulations, practical assessments, and browser-local progress.

The customer router defaults to PPPoE and Google DNS (8.8.8.8). The wrong-WAN-mode exercise starts with DHCP and requires correcting it to PPPoE. These are simulated values, not live network configuration.

**Important:** GitHub Pages is public unless access is separately controlled. Do not add live customer details, credentials, or internal network IPs. No live Splynx or network connections are made.
